# Portfolio Website – Complete Change Log & Updates

## 1. Experience & Timeline Updates

*   **Purble Bird**: Added the "Graphic Designer" role along with the official Purble Bird logo to the experience timeline.

## 2. Tools & Skills Section

*   **New Software Added**: Added Adobe Premiere Pro and Adobe After Effects to the text list in the "Tools & Software" section.
*   **Hero Section Icons (Size Fix)**: Removed the invisible padding from the 3D After Effects (Ae) image. Set it next to Illustrator (Ai) so that all icons (Figma, Xd, Ps, Canva, Pr, Ai, Ae) are perfectly aligned and completely even in size.

## 3. Media & Interactive Features

*   **Custom Music Player**: Integrated a functional music player that plays `song.mp3`. Added a spinning vinyl/CD animation that rotates while the music plays and stops instantly when paused. Increased the player's size for better visibility.
*   **Resume Download**: Linked the primary "Resume" button directly to `Prathap.resume.pdf` so it triggers an automatic download when clicked, and removed duplicate/unwanted resume buttons.
*   **Videos Link (Projects Section)**: Added a "Videos" button next to "Poster Design" with a custom camera SVG icon. Hovering over it shows the Google Drive link tooltip, and clicking it opens the specific Drive folder in a new tab.
*   **Hero Logo Backgrounds**: Removed white backgrounds from various profile/hero logos and aligned them perfectly next to existing branding.

## 4. Bug Fixes & Performance

*   **White Screen Refresh Bug**: Fixed a critical glitch where refreshing the page while scrolled down resulted in a locked, plain white screen.
*   **Solution**: Upgraded the intro name glow animation (`intro-reveal`) to a fixed position and forced the browser to reset scroll to the top (`window.scrollTo(0, 0)`) on every reload. The name glow animation now plays flawlessly on every refresh.
*   **Continuous Archiving**: Packaged all the updated CSS, HTML, JS, and optimized image assets safely into `portfolio_website.zip` after every major feature update.
